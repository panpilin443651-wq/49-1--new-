# ระบบคุมค่าใช้จ่าย 49(1) — ฝ่ายเศรษฐกิจยาง

เว็บแอปคุมงบประมาณ 49(1) ใช้ข้อมูลชุดเดียวกันทุกคน เข้าด้วยรหัสผ่านร่วม

## หน้าจอ

ภาพรวม · งบประมาณ · การเบิกจ่ายรายเดือน · เปรียบเทียบรายปี · หมวดรายจ่าย · หน่วยงาน · ตั้งค่า

- ปีงบประมาณไทย ตุลาคม → กันยายน
- หมวดรายจ่าย 2 หมวดใหญ่ (ค่าตอบแทนใช้สอยและวัสดุ / ค่าสาธารณูปโภค) เพิ่ม แก้ไข ลบ และสลับลำดับได้
- นำเข้า/ส่งออก CSV · สำรองและกู้คืนข้อมูลเป็น JSON
- โหมดมืด/สว่าง · ใช้บนมือถือได้

## โครงสร้าง

```
index.html            หน้าเว็บทั้งหมด (ไม่ใช้เฟรมเวิร์ก ไม่ต้อง build)
api/auth.js           เข้าสู่ระบบด้วยรหัสผ่านร่วม (คุกกี้ HttpOnly)
api/data.js           อ่าน/เขียนข้อมูลกลาง
api/_lib.js           ตัวช่วยต่อ Supabase (REST) + ตรวจรหัสผ่าน
supabase.sql          สคริปต์สร้างตาราง รันครั้งเดียวใน SQL Editor
ข้อมูล/                ไฟล์ต้นฉบับ 49(1) ฝศย..xlsx (ไม่ขึ้นเว็บ)
นำเข้า/                ข้อมูลที่แปลงแล้ว JSON/CSV (ไม่ขึ้นเว็บ)
```

ข้อมูลที่ใช้ร่วมกัน (หน่วยงาน หมวด งบจัดสรร ค่าใช้จ่าย เกณฑ์สี ปีงบ) เก็บบนเซิร์ฟเวอร์
ส่วนค่าที่เป็นของแต่ละเครื่อง (ปีที่กำลังดู โหมดมืด ซ่อนเมนู ชื่อผู้บันทึก) เก็บในเบราว์เซอร์

แต่ละรายการเก็บเป็นคนละช่องในฐานข้อมูล เวลาสองคนบันทึกคนละรายการพร้อมกันจึงไม่ทับกัน
และหน้าเว็บจะส่งขึ้นเซิร์ฟเวอร์เฉพาะรายการที่เปลี่ยนจริงเท่านั้น

## ติดตั้ง

**1. สร้างตารางบน Supabase** — เปิดโปรเจกต์ที่ supabase.com → SQL Editor → New query
วางเนื้อหาไฟล์ `supabase.sql` ทั้งไฟล์ → Run (สร้าง 3 ตารางพร้อมสิทธิ์ให้ anon key)

**2. ตั้งตัวแปรที่ Vercel** — Settings → Environment Variables (ติ๊กครบทั้ง Production / Preview / Development)

| ตัวแปร | ค่า | หาได้จาก |
|---|---|---|
| `SUPABASE_URL` | https://xxxx.supabase.co | Supabase → Project Settings → Data API → Project URL |
| `SUPABASE_ANON_KEY` | eyJhbG… | หน้าเดียวกัน หัวข้อ Project API keys → anon public |

**3. Redeploy** หนึ่งครั้ง แล้วเปิดเว็บ ใส่ชื่อผู้ใช้/รหัสผ่าน — ครั้งแรกระบบจะย้ายข้อมูลปีงบ 2566–2569 ขึ้นฐานข้อมูลให้เอง

ตรวจว่าพร้อมหรือยัง: เปิด `/api/auth` ต้องได้ `"ready":true`

anon key ถูกเก็บไว้ที่เซิร์ฟเวอร์ Vercel เท่านั้น ไม่ได้ถูกส่งลงไปในหน้าเว็บ

## ชื่อผู้ใช้ / รหัสผ่าน

ค่าตั้งต้น: **raot / 1234**

เปลี่ยนได้ที่ Vercel → Settings → Environment Variables โดยเพิ่ม `APP_USER` และ `APP_PASSWORD`
แล้ว Redeploy หนึ่งครั้ง (ทุกคนต้องเข้าสู่ระบบใหม่)

> ⚠️ ลิงก์ที่ Vercel เปิดสาธารณะ ใครมีลิงก์และเดารหัสได้ก็แก้ตัวเลขงบได้
> ควรตั้ง `APP_PASSWORD` เป็นรหัสที่เดายากเมื่อเริ่มใช้งานจริง

## ที่มาของข้อมูล

แปลงจาก `ข้อมูล/49(1) ฝศย..xlsx` โดยอ่านเฉพาะเซลล์ระดับรายการ ไม่ใช้แถวยอดรวมในไฟล์ซึ่งค้างอยู่
ตรวจกระทบยอดกับคอลัมน์ "คงเหลือ" ของทุกแถวแล้ว (คงเหลือ = จัดสรร − ผลรวม 12 เดือน)

| ปีงบ | งบจัดสรร | เบิกจ่าย |
|---|---:|---:|
| 2566 | 1,925,990.00 | 1,225,068.79 |
| 2567 | 2,065,651.00 | 662,620.28 |
| 2568 | 2,148,774.00 | 714,917.10 |
| 2569 | 2,161,840.00 | 1,176,717.50 |

ค่าใช้จ่ายเป็นยอดรวมรายเดือน (ไฟล์ต้นทางมีแค่ยอดต่อเดือน) ลงวันที่สิ้นเดือน
งบค่าจ้างเหมาบริการใช้ตัวเลขจากตารางสัญญาย่อย ซึ่งไม่ตรงกับตารางหลักในปี 2567–2569
